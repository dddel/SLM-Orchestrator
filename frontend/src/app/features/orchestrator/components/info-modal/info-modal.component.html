Riassunto dell'Applicazione

Microservizio e Single Page Application di orchestrazione neuro-simbolica per Small Language Models (1-4B) in esecuzione locale su Ollama. Il sistema combina instradamento intelligente (routing dinamico), decoding vincolato guidato da JSON Schema e validatori formali deterministici (Codice Fiscale con algoritmo di omocodia, Partita IVA con algoritmo di Luhn, IBAN e RFC 5322 Email) per garantire l'assoluta conformità formale e semantica dell'output.
